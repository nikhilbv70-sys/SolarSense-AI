How detection works

Every rule is visible here

  • Checks run only when the irradiance reading is at least 200 W/m² (daylight).
  • An alert is raised after 3 consecutive intervals below −15% (underperformance) or above +25% (output above expected).
  • Alerts clear when the deviation returns within the normal band.
  • Evidence checks count what the data supports. They never confirm a physical fault.
